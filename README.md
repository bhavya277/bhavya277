## `04` — selected work

> A collection of things I'm building while learning how intelligent systems work.

### ◈ Associative Memory & Fast-Weight Architectures

**Research / Experimental**

Exploring how fixed-size recurrent states can store and retrieve key-value associations through linear recurrence.

```text
Sₜ = λSₜ₋₁ + vₜkₜᵀ
```

The goal is to make the underlying mechanism **interactive, observable, and experimentally verifiable** rather than treating the architecture as a black box.

**DataForge × Pathway 2026**
